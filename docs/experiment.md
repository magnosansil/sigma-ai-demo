# Experimento

## Objetivo

Investigar como diferentes níveis de planejamento e contexto influenciam o resultado produzido por um LLM durante o desenvolvimento de uma aplicação web.

## Variáveis controladas

- modelo utilizado;
- tarefa;
- stack;
- requisitos;
- dados;
- design;
- funcionalidades.

## Variável independente

Nível de planejamento.
