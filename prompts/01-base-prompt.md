# Base Prompt

Você é um desenvolvedor frontend sênior.

Crie uma aplicação web de e-commerce chamada SIGMA, uma marca premium de roupas e acessórios esportivos.

## Tecnologia

- Next.js
- TypeScript
- React

## Funcionalidades

- página inicial;
- catálogo;
- filtros;
- página de produto;
- carrinho;
- checkout.

## Design

A aplicação deve possuir uma estética premium, moderna e sofisticada.

Utilize:

- animações;
- microinterações;
- elementos 3D em pontos estratégicos;
- design responsivo.
